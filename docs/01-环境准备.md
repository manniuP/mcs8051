# 01 环境准备

## 1. 目标

在 Windows 上准备出两套编译器，使同一个工程里的 C 与 Zig 都能编成
SDCC 的 ASxxxx 目标文件：

- C：**SDCC**（本机 4.5.20），提供 `sdcc.exe`、`sdas8051.exe`、`sdld.exe`；
- Zig：本仓库自举的 **`zig/zig-out/bin/zig.exe`**，自带 MCS 后端。

## 2. SDCC（C 侧）

本机安装路径约定：

```
C:\Program Files (x86)\SDCC\bin\sdcc.exe
C:\Program Files (x86)\SDCC\bin\sdas8051.exe
C:\Program Files (x86)\SDCC\bin\sdld.exe
```

检查版本：

```powershell
& 'C:\Program Files (x86)\SDCC\bin\sdcc.exe' --version
```

本机 SDCC **只支持 `-mmcs51`**，不支持 `-mmcs251`。因此默认走 AI8051U 的
8051 兼容模式；要使用 251 核，需先自行编译 `sdcc-c251`（见 05 篇）。

## 3. 自举 Zig 编译器（Zig 侧）

`zig/` 是基于上游 0.16.x 的源码树，用发行版 Zig 0.16.0 来构建它。
构建时把 `ZIG_LIB_DIR` 指向本树的 `lib/`，保证 `std` 与源码一致：

```powershell
$env:ZIG_LIB_DIR = "<workspace>\mcs251\zig\lib"
& "$env:LOCALAPPDATA\Microsoft\WinGet\Packages\zig.zig_Microsoft.Winget.Source_8wekyb3d8bbwe\zig-x86_64-windows-0.16.0\zig.exe" `
    build -Dno-lib -Dno-langref
```

- 工作目录：`mcs251\zig`
- 产物：`mcs251\zig\zig-out\bin\zig.exe`
- 首次构建约 1~2 分钟；改后端源码后需重新构建。

> `-Dno-lib` / `-Dno-langref` 表示不重新生成标准库与语言参考，加快构建。

## 4. 验证环境

### 4.1 Zig 后端能出汇编

```powershell
$zig = "<workspace>\mcs251\zig\zig-out\bin\zig.exe"
Set-Content -Path empty.zig -Value 'export fn main() void {}' -Encoding ASCII
& $zig build-obj -target mcs51-freestanding "-femit-bin=empty.asm" empty.zig
```

成功会得到 `empty.asm`（ASxxxx 汇编文本）。

### 4.2 SDCC 能编 C

```powershell
$sdcc = 'C:\Program Files (x86)\SDCC\bin\sdcc.exe'
& $sdcc -mmcs51 --model-large -c t.c -o t.rel
```

成功会得到 `t.rel`。

### 4.3 头文件

工程用到的头文件位于：

- `include/`：`c51.h`（SDCC 语法宏）、`ai8051u_sfr.h`（AI8051U 寄存器）、`mcs_intrins.h`；
- `port/stc-hal/`：STC 官方 AI8051U HAL 的 SDCC 化版本（GPIO、Delay、UART 等）。

编译 C 时用 `-I` 指到这两个目录：

```powershell
& $sdcc -mmcs51 --model-large -I <repo>\include -I <repo>\port\stc-hal -c main.c -o main.rel
```

> 注意：SDCC 的 `-I` 要与路径**分开写**（`-I <dir>`）。写成 `-I<dir>`（紧贴）
> 在本机 SDCC 上找不到头文件。

## 5. 器件与主频

- 目标器件：STC **AI8051U**。
- 主频在 `port/stc-hal/config.h` 的 `MAIN_Fosc` 中定义（示例工程为 40MHz）。
- 烧录时用 STC-ISP 把目标主频调成与 `MAIN_Fosc` 一致，否则 `delay_ms()` 不准。

## 6. 可选：MCS-251 工具链

若需 251 核，按 `driver/README.md` 第 5 节与 `tools/wsl_build_sdcc.sh`
在 WSL 中编译 `sdcc-c251`，得到 `sdas251.exe` 与支持 mcs251 的 `sdld.exe`。
详见 [05-移植到MCS-251](05-移植到MCS-251.md)。
