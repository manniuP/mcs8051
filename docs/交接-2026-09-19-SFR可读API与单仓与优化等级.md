### 1.5 优化等级逐级化（B1，后端，已重编）
- `Gen.opt_level`（来自 `linksection` 标签 / 全局 `-O*`：`-OReleaseSmall→Os`、`-OReleaseFast→Ofast`、其余 `O3`）。
- **O2/O3/Ofast → 比较+`cond_br` 融合**（范围安全：短条件反向跳过 + 远跳 `ejmp`）；**O0/O1 不融合**；
  `Os` 同前（融合 + 直接短跳 + 冷区）。O1 暂与 O0 相同。
- 注意：融合若直接短跳远处目标会 `Branching range exceeded`（sdas251）——已改为范围安全形式。

### 1.6 设备表（D1/D2）
- 手册 11.1 核实：**STC32G12K128 复位入口/向量 = FF:0000**，Flash = FE:0000–FF:FFFF（128K）。
  旧 `base=0x000000` 错，已改 `base/reset=0xff0000`、eeprom/中断向量同步；工具把单段钳到地址空间顶部
  （128K→顶部 64K，其余留未来拆分链接）。
- `docs/19-设备表.md` 写就；`examples/ai8051u/dev/led.zig` 改用 `dev.reg`/`dev.p`
  （`dev.reg.write` 仅 comptime，运行期值用 `dev.p.*`）。

### 1.7 修既有 bug：8 位全局互操作
- 现象：`simtest` `failcode=0x41`（Zig `counter` 与 C `extern counter` 不一致）。
- 根因：`device.decide` 把 Zig `export var`（≤2B）自动放 **DSEG**，而 C `--model-large` 的 extern 在
  **xdata** → 访问不同存储。
- 修：`device.decide` 加 `arch`；**mcs51 默认 xdata**（显式 `linksection` 仍优先），251 不变。
  验证 `simtest` → `aa 00 02 04 08 10 20 40`（通过）。`ci.ps1` sim 步改为**自动生成 `simtest.cmd`**。
- 遗留：251 侧与 C 共享全局建议显式 `linksection(".xdata")`。

## 2. 关键坑（务必看）

- **命名空间撞名**：`dev.sfr/reg/p` 同名寄存器在同一编译单元会撞 `_<name>`。
- **R6 尾语句不融合**：函数最后一条 RMW 后 A 可能是返回值（4 字节返回 `A:B:DPH:DPL`）→ 安全起见不融合。
- **短跳范围**：后端融合/跳转对 far 目标必须用远跳（`ejmp/ljmp`），否则 sdas251 报越界。
- **8 位 export 全局必须 xdata**（C `--model-large` 约定）。
- **`forms.zig` 是生成物**，勿手改（`tools/gen_mcs_forms.py`）。
- **重编编译器**：系统 zig `zig build -Doptimize=ReleaseFast -Dno-lib -Dmcs-only --zig-lib-dir compiler/lib`。
