# 28 编程指南（Zig / C → MCS-251 / MCS-51）

> 面向：用本工具链写固件的人。**速查 + 惯例**；细节分别见 [06 常见问题/限制](06-常见问题与限制.md)、
> [19 设备表](19-设备表.md)、[23 SFR 可读 API](23-寄存器操作与SFR可读API.md)、[17 优化标签](17-后端IR提示与中间层优化.md)。
> 示例源码在 `examples/`（`ai8051u/`、`at89c52/`）。

## 0. 三句话

- **Zig** 由自研后端直出 ASxxxx 汇编；**C** 走 SDCC（`-mmcs251`/`-mmcs51`）；两者用 `sdas`+`sdld`/`sdcc`
  链成同一个 `.ihx`。
- 构建：`xmake f --mcs_arch=mcs251`（8 位用 `mcs51`，注意**下划线**）→ `xmake build <目标>`；
  产物统一在 `build/examples/<平台>/<名>/`。
- SFR 用**生成的 `dev` 模块**（`dev.sfr` / `dev.reg` / `dev.p`），别手抄地址。

## 1. 最小纯 Zig 程序

```zig
// examples/ai8051u/sfr_ptr/led.zig（节选）
const dev = @import("dev");
export fn main() void {
    dev.p.P1M1.* &= ~@as(u8, 0x02); // P1.1 推挽
    while (true) {}
}
```
纯 Zig 目标自带 `crt0.asm`（复位 `FF:0000` → `ejmp __start` → `ecall _main`），链接 `--code-loc 0xff0000`。
构建注入命名模块：`--dep mcs -Mmcs=lib/mcs251.zig --dep dev -Mdev=build/devices/device_sfr.zig`。

## 2. SFR 访问（三种风格，按场景选）

| 风格 | 写法 | 适合 |
| --- | --- | --- |
| 宏/位指令（`mcs`） | `m.sfrAnd(0x91, ~@as(u8,0x02))` / `m.bitSet(dev.sfr.P1,1)` | 位指令 `setb/clr/cpl`、`anl/orl/mov dir8,#imm` 单条 |
| 寄存器对象 | `dev.reg.P1M1.anl(~0x02)` / `dev.reg.P1.clr(1)` | 面向**编译期常量**，读法最像 C |
| C 风格指针 | `dev.p.P1M1.* &= ~0x02;` | 自然 C 写法；**运行期值**也能写 |

- `dev.reg.write/read` 等参数是 `comptime`，**运行期值用 `dev.p.*`（指针）**。
- `dev.sfr.NAME` 是地址常量（`u16`，给宏用，需 `@intCast`）。
- **坑**：`dev.sfr`/`dev.reg`/`dev.p` **同一 `.zig` 内不要引用同一寄存器**（后端按短名发 `_<name>`，会撞名）。
- 构建层 `mcs_opt` 的 **R6** 会把 `dev.p.X.* op= imm` 融成单条（`anl/orl/xrl dir8,#imm`）。

## 3. 数据空间与放置

- 默认：全局 → 设备默认数据空间（多数字号 xdata），局部 → 栈（251 SPX / 51 静态帧）。
- 显式放置（`linksection`，可空格组合优化等级）：`m.data`/`m.idata`/`m.edata`/`m.xdata`/`m.exdata`：
  ```zig
  var fast: u8 linksection(m.data) = 0;         // 直接寻址（快）
  var big: [64]u8 linksection(m.xdata) = undefined;
  ```
- **自动放置**（设备表）：251 上 ≤2B → data、其余 → 设备默认；**8 位默认 xdata**（保证与 C 互操作）。
- **与 C 共享的全局**：一律 xdata → 251 侧请显式 `linksection(m.xdata)`（自动放置可能落 data 与 C 失配）。
- `exdata`（片外）放置**未验**。

## 4. 优化等级（`linksection` 标签，GCC 对齐）

`m.O0`–`m.O3` / `m.Ofast` / `m.Os`（无标签默认 `O3`，跟随全局 `-O*`）：
- **O2/O3/Ofast**：启用「比较紧跟 `cond_br`」融合（少一次 bool 物化）。
- **O0/O1**：不融合（目前 O1=O0）。
- **Os**：体积优先（融合 + 直接短跳 + 冷区 `COLD`/`COLDX`）。构建加 `-Dmcs-small=true` 走 `-OReleaseSmall`。

## 5. 中断 / ISR

- ISR 用 `export fn` + **无操作数内联汇编**（存 ACC/PSW → `ecall _handler` → 恢复 → `reti`），
  向量表写在 `crt0.asm` 的 HOME 区。
- **ISR 必须无栈帧**：带局部量的 Zig 代码会加 `spx` prologue/epilogue，而 `reti` 跳过 epilogue →
  每次中断泄漏 SPX。把「活」放普通 `export fn`，由 ISR `ecall` 调用。
- 示例：`examples/ai8051u/zig_t0print`（T0 1ms 中断里打 UART）、`zig_irq`、`zig_irq_all`。

## 6. C ↔ Zig 互操作

- C 侧 `sdcc --stack-auto`；参数0 → DPL/DPH/B/A，参数2..N 逆序压栈；返回 DPL/DPH/B/A。
- 指针：`__xdata T*`（8 位 2 字节）↔ Zig `[*]T`（经 DPTR+MOVX）；251 指针 3 字节（`@dr28`）。
- **全局变量符号**：Zig `export var` ↔ C 同名 `extern`，**双方都按 xdata**（见 §3 的坑）。
- 多参数跨语言仍建议先写一致性测试；示例 `examples/ai8051u/ptrtest`、`examples/at89c52/sim`（8 位自检）。

## 7. 常用库（`lib/`）

- `cobs/`：COBS + 日志帧（**可重入**：Zig `Encoder` / C `cobs_enc_t`）；只写进调用方缓冲区。示例 `ziglog`/`ccobs`。
- `uart251/`：UART1；`stc-hal/`：STC HAL；`mdu/`：32 位硬件乘除；`cordic/`；`include/`：`c51.h`、`ai8051u_sfr.h`。
- **尺寸注意**：后端对每个内联调用点各出一份代码；库函数用普通 `fn`（非 `inline`）避免膨胀。

## 8. 构建与产物

- `xmake f --mcs_arch=mcs251 [--device=devices/stc/<型号>.toml] [--mcs_small=true] [--zig=<路径>]`。
- 目标：`zigled`/`zigasm`/`zigsfrbits`/`zigsfrreg`/`zigsfrptr`/`zigopt`/`zigbench`/`zigmem`/`zigirq`/`zigprint`/
  `ziguart`/`ziglog`/`zigbuzz`/…；`simtest`/`ccobs51`（8 位）；`devhdr`/`devled`/`devzig`（设备表）。
- 产物在 `build/examples/<平台>/<名>/`（`.ihx`/`.cdb`/`.asm`/`.map`）；设备生成物在 `build/devices/`。
- **便携集**：`tools/make_portable.ps1` 打包（自带 zig/sdcc/mcstools，目标机零环境变量）；示例 `examples/ai8051u/*/portable/`。

## 9. 调试

- **Zig CDB**：调试档（默认 `-ODebug`）产 SDCC 风格符号，链接加 `--debug` → `.cdb`；外部调试器
  `tools/mcs_dbg.py`（CDB + QEMU GDB RSP）、DAP `tools/mcs_dap.py` + VSCode 扩展 `tools/vscode-mcs251/`。
- **QEMU（mcs251）**：`wsl -e bash tools/qemu_mcs_run.sh <ihx>`（或自建脚本）；SFR 读走 QMP `xp`。
- **8 位仿真**：ucsim_51（`-t STC15`），无板可验；`examples/at89c52/sim`（`simtest`）。
- **真机 AI8051U-34K64**：`--code-loc 0xff0000`、IO 默认高阻需配 `PxM0/PxM1`、烧录用 AiCube-ISP。

## 10. 常见坑（速查）

- `--mcs_arch` 是**下划线**；`MCS_DEVICE`/设备表决定放置与链接布局。
- 命名空间撞名（§2）；`dev.reg` 仅 comptime（§2）；C 共享全局用 xdata（§3）。
- ISR 无栈帧（§5）；切片越界会生 `Lxx` 标签（构建层已自动修，仍建议少用）。
- Zig 代码保持 **0.16 兼容**（编译器/ZLS 都是 0.16）。
- 源文件里的 `.asm` 生成物现集中在 `build/`（源码目录只留源）。
