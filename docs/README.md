配套示例工程：

- [`../projects/ai8051u_blink/`](../projects/ai8051u_blink/) —— C + Zig 流水灯（C 用 STC HAL 驱动 P1，Zig 算图案）。

一句话概括本仓库的定位：

- **Zig**：由自举后端 `zig/src/codegen/mcs/` 直接产出 ASxxxx 汇编（`.asm`）。
- **C**：由 SDCC（`-mmcs51` / `-mmcs251`）产出 `.rel`。
- **链接**：两者都是 SDCC ASxxxx 目标，用 `sdas` + `sdld`（或 `sdcc` 驱动）链成同一个 Intel HEX。
