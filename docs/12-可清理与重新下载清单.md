# 可清理文件与重新下载清单

> 用途：把当前工作流（**不自举**，只走 `zig 编译 Zig 源 + sdcc 编译 C + 链接`）用不到的
> 大件清掉，腾出磁盘；日后需要时按本页“恢复方法”重新获取。
> 记录时间：2026-09-14。

## 一、本次清理（可自动重建 / 可重新下载）

| 项目 | 大小 | 说明 | 清理后如何恢复 |
| --- | --- | --- | --- |
| `vendor/keil/` | ~299 MB | Keil C51/C251/UV4 安装（安装包本体）。本项目**用不了**其二进制/工程（见 PLAN G），构建与文档均不引用它 | 从 Keil/STC 重新安装或下载 |
| `sdcc-c251/` | ~289 MB | SDCC MCS-251 downstream 源码（`-mmcs251` 端口）。仅在**重编 sdcc251 工具链**或重生成指令表时需要 | `git clone https://github.com/zevorn/sdcc-c251`（版本 4.6.0） |
| `.zig-cache/` | ~40 MB | xmake 调 zig 时生成的全局缓存（mcs 目标 std 的编译产物） | 下次 `xmake build` 自动重建 |
| `.xmake/` | <1 MB | xmake 自身配置/缓存 | 下次 `xmake f` 自动重建 |
| `sdcc-c251-build.log` | <1 MB | 曾经构建 sdcc-c251 的日志 | 无需恢复（历史日志） |
| `projects/ai8051u_ptrtest/` 构建产物 | <1 MB | `*.asm/*.rel/*.ihx/*.lst/*.rst/*.sym/*.map/*.mem/*.lk` | `xmake build ptrtest` 重新生成 |

合计约 **630 MB**。

## 二、恢复方法（按需）

```powershell
# 1) sdcc-c251 源码（若要重编 MCS-251 工具链）
git clone https://github.com/zevorn/sdcc-c251 sdcc-c251
#    然后参考 docs/08、docs/05 与 tools/wsl_build_sdcc.sh 在 WSL 里构建

# 2) Keil 安装（仅在需要 Keil 交叉验证时）
#    从 STC 官网/Keil 官网下载安装到 vendor/keil

# 3) 缓存与工程产物
xmake f --mcs_arch=mcs251
xmake build ptrtest
```

## 三、明确保留（不要删）

| 项目 | 原因 |
| --- | --- |
| `tools/zig-bootstrap/zig.exe` | 唯一可用的 55 MB 预编译编译器（本项目核心工具） |
| `tools/zig-bootstrap/zig.pdb` | 该编译器**唯一**的调试符号（无法重新生成，排障时要符号化栈回溯） |
| `sdcc-mcs251-windows-x64/` | 预编译 SDCC 4.6.0 mcs251 工具链（`sdcc`/`sdas251`/`sdld`），直连管线的必需件 |
| `zig/`（源码 + `lib`） | `zig/lib` 是 `ZIG_LIB_DIR` 必需的 std（含 mcs51/mcs251 目标定义）；源码由 git 跟踪，可 `git checkout` 恢复 |
| `vendor/stc/` | ~1.6 MB，`tools/keil2sdcc*.py` 重新生成 SFR 头时要用，且极小 |
| `include/ port/ projects/*.c,*.zig driver/ docs/` | 源码与文档 |

> `tools/gen_mcs_forms.py` 会读 `sdcc-c251/sdas/as251/tests/*.tsv`；删除 `sdcc-c251`
> 后该脚本暂时不能跑，待重克隆即可。

## 四、git 可恢复 vs 需重新下载

- **已被 git 跟踪**的（如 `zig/`、`include/`、`docs/`、`projects/` 源码）：误删可直接
  `git checkout -- <path>` 恢复，不需要下载。
- **未跟踪且被 `.gitignore` 忽略**的（如 `vendor/`、`sdcc-c251/`、
  `sdcc-mcs251-windows-x64/`、`tools/zig-bootstrap/`、各类 `.zig-cache*`）：删了只能按
  本页方法重新下载/重建。
