# 工程与示例总览

`examples/` 按**芯片/平台**分目录（2026-09-19 整理）：

```
examples/
  ai8051u/            AI8051U（MCS-251 32 位；部分示例也支持 8 位模式）
  at89c52/            AT89C52 / 通用 8 位 MCS-51（ucsim 仿真，无需硬件）
  portable/           便携工具链打包模板（tools/make_portable.ps1 用）
  vscode_c_cmake/     VS Code + CMake 集成示例（纯 C，平台无关）
  vscode_mixed_xmake_zig/  VS Code + xmake 的 C/Zig 混编集成示例
```

通用约定：Zig 示例由 MCS 后端出 ASxxxx 汇编，C 由 SDCC 出 `.rel`，`sdas` + `sdld`/`sdcc`
链接；纯 Zig 目标用自带 `crt0.asm`，`--code-loc 0xff0000`（AI8051U 程序存储器在 `FF:0000`）。
构建前先 `xmake f --mcs_arch=mcs251`（8 位示例用 `mcs51`）。SFR 地址来自设备表生成的
`dev` 模块（见 [23](23-寄存器操作与SFR可读API.md)）。

**构建产物集中在 `build/examples/<平台>/<名>/`**（如 `build/examples/ai8051u/zig_led/led.ihx`），
源码目录里只留源文件（`.c/.zig/crt0*.asm` 等）。故 `.gitignore` 只需忽略 `build/`；
改名/移动示例只需同步 `xmake.lua` 里的 `scriptdir`，产物路径由 `outdir` 自动跟随。

## 一、AI8051U（`examples/ai8051u/`，默认 `--mcs_arch=mcs251`）

| 示例 | xmake 目标 | 说明 |
| --- | --- | --- |
| `blink/` | `blink` | C（STC HAL 驱动 P1）+ Zig 计算图案的流水灯 |
| `ptrtest/` | `ptrtest` | C↔Zig 3 字节指针互操作（M3） |
| `led/`、`uart/` | `led`、`uart` | C 点灯 / UART1 收发 |
| `dev/` | `devzig` | **设备表驱动**纯 Zig：`dev.sfr.*` + 变量按存储表自动放置 |
| `sfr_bits/` | `zigsfrbits` | SFR **位指令**风格（`m.sfrAnd/sfrOr/bitSet/bitClr` + `dev.sfr.*`） |
| `sfr_reg/` | `zigsfrreg` | SFR **寄存器对象**风格（`dev.reg.P1M1.anl(~0x02)` / `.clr(1)`） |
| `sfr_ptr/` | `zigsfrptr` | SFR **C 风格固定地址指针**（`dev.p.P1M1.* &= ~0x02;`，R6 融为单条） |
| `zig_led/`、`zig_asm/` | `zigled`、`zigasm` | 纯 Zig 点灯（指针风格 / `mcs` 宏位操作） |
| `zig_irq/`、`zig_irq_all/` | `zigirq`、`zigirqall` | 中断向量/ISR（T0；全中断向量表） |
| `zig_t0print/` | `zigprint` | T0 1ms 中断里每秒 UART1 打印（ISR 无栈帧） |
| `zig_uart_echo/` | `ziguart` | UART1 接收中断回环（环形缓冲） |
| `zig_opt/` | `zigopt` | 放置/优化等级标签（`linksection` + `O0–O3/Ofast/Os`） |
| `zig_bench/` | `zigbench` | Timer0 1T 周期测量（读延迟 / O 级 / 循环改写） |
| `zig_mem/` | `zigmem` | 写互异模式回读校验四空间（data/idata/edata/xdata） |
| `zig_rtindex/`、`zig_slice/`、`zig_rtslice/`、`zig_ns/` | `zigrtindex`、`zigslice`、`zigrtslice`、`zigns` | 运行期下标/切片/结构体等后端能力演示 |
| `zig_buzz/` | `zigbuzz` | xdata 乐谱 + T0 中断驱动无源蜂鸣器 |
| `zig_log/` | `ziglog` | COBS 二进制日志帧（`decode.py`/`decode.ps1` 主机解码） |
| `zig_hotcold/` | `zighotcold` | 热/冷代码与数据分区 |
| `c_cobs/` | `ccobs` | C 版 COBS 日志帧 |
| `cmd/` | `cmd` | 命令帧（`host/cmd.py` 上位机） |
| `mdu/` | `mdu` | 32 位硬件乘除（MDU/DMAIR） |
| `usb_cdc/`、`usb_hid/`、`usb_cdc_cobs/` | `usbcdc`、`usbhid`、`usbcdcobs` | USB-CDC / HID / CDC+COBS（C，SDCC，见 [14](14-USB-CDC移植笔记.md)） |

## 二、AT89C52 / 通用 8 位 MCS-51（`examples/at89c52/`，需 `xmake f --mcs_arch=mcs51`）

| 示例 | xmake 目标 | 说明 |
| --- | --- | --- |
| `sim/` | `simtest` | 8 位自检：C 调 Zig 逻辑并校验，结果写 XRAM；`ucsim_51` 可直接跑 |
| `c_cobs/` | `ccobs51` | 8 位 C 版 COBS 编码自检（`sim.cmd` 在 ucsim 里 dump XRAM 核对） |

## 三、新建工程

复制同族里最简单的示例（AI8051U 用 `sfr_ptr/` 或 `zig_led/`；8 位用 `sim/`），改源码与
`xmake.lua` 里的目标即可。步骤与 ABI 约定见 [01](01-环境准备.md)、[03](03-C与Zig混编与ABI.md)、
[02](02-工程结构与构建流程.md)。
