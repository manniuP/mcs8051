## 2. 三段式流程

```
Zig 源  ──(zig build-obj)──▶  .asm  ──(sdas8051/sdas251)──▶  .rel ─┐
                                                                    ├─(sdld / sdcc)─▶ .ihx
C 源    ──(sdcc -c)────────────────────────────────────▶  .rel ─┘
```

- **Zig → `.asm`**：`-target mcs51-freestanding` 或 `mcs251-freestanding`。
- **`.asm` → `.rel`**：`sdas8051 -plosgffw out.rel out.asm`。
- **C → `.rel`**：`sdcc -mmcs51 --model-large -c`。
- **链接**：用 `sdcc` 驱动最省事（自动带 SDCC 启动代码与运行时库），
  也可用 `sdld` 手动链接（独立、不带库时需自带 `crt0`）。

## 3. 目标三元组与命名

| 项 | MCS-51 | MCS-251 |
| --- | --- | --- |
| Zig target | `mcs51-freestanding` | `mcs251-freestanding` |
| SDCC 目标 | `-mmcs51` | `-mmcs251` |
| 汇编器 | `sdas8051` | `sdas251` |
| 指针宽度 | 16 位（2 字节） | 24 位（3 字节） |
| 字节序（标量） | 小端 | 大端 |
| 调用返回 | `ret` | `eret` |

符号统一加 `_` 前缀：C 的 `main` 在汇编里是 `_main`，Zig 的 `export fn foo`
是 `_foo`。这一点两套工具一致，因此可直接互相引用。

## 4. 代码区与存储区

- 代码：`.area CSEG    (CODE)`（两套工具一致）。
- MCS-51 的 Zig 后端把局部/临时量放在静态内部 RAM 帧：
  `.area DSEG` + `_frkN:` + `.ds n`（SDCC 默认的**非重入**布局）。
- SDCC 的 C 还会用 `HOME`、`GSINIT0..5`、`GSFINAL`、`RSEG`、`BSEG`、`XSEG`
  等区；用 `sdcc` 驱动链接时会自动带上启动片段，把库按需拉入。

## 5. 手工命令（最小可复现）

设 `<repo>` 为仓库根：

```powershell
# --- C 侧 ---
$sdcc = 'C:\Program Files (x86)\SDCC\bin\sdcc.exe'
$sdas = 'C:\Program Files (x86)\SDCC\bin\sdas8051.exe'
& $sdcc -mmcs51 --model-large -I <repo>\include -I <repo>\port\stc-hal -c main.c -o main.rel

# --- Zig 侧 ---
$env:ZIG_LIB_DIR = '<repo>\zig\lib'
& <repo>\tools\zig-bootstrap\zig.exe build-obj -target mcs51-freestanding "-femit-bin=led.asm" led.zig
& $sdas -plosgffw led.rel led.asm

# --- 链接成 Intel HEX（sdcc 自动加启动与库）---
& $sdcc -mmcs51 --model-large main.rel led.rel -o blink.ihx
```

> `-femit-bin=` 后接路径时，建议整体加引号：`"-femit-bin=...\led.asm"`，
> 避免 PowerShell 把它拆成多个参数。

产物：

- `main.rel`、`led.rel`：可重定位目标；
- `blink.ihx`：Intel HEX（可直接烧录）；
- `blink.map`、`*.lst`、`*.rst`、`*.sym`：链接/汇编清单，便于核对符号与地址。

## 6. 两种链接方式

1. **带 SDCC 库（推荐做完整工程）**：用 `sdcc` 驱动，或 `driver\build.ps1 -UseSdccLibs`。
   会拉入 SDCC 启动代码（`HOME/GSINIT`）与运行库。
2. **独立最小链接（学习/裸机）**：用 `driver\build.ps1`（默认）自带
   `crt0-*.asm`，只把 `CSEG` 放到 0x0000。适合单个 Zig `main`。

> 现有 `driver/build.ps1` 只接受**一个 Zig 源**。C + Zig 混编请用工程内自带的
> `build.ps1`（见 [04-驱动脚本用法](04-驱动脚本用法.md) 与示例工程）。
